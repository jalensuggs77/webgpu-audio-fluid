# CYBER FLUID · 赛博流体沙盒

基于 **WebGPU + Three.js (TSL)** 的浏览器端百万级 GPU 粒子流体沙盒。通过 **Web Audio API** 接入麦克风或本地音乐，粒子会随低音（Bass）**炸裂**、再被弹簧场**重组**成新的形态；右侧是一套**暗黑毛玻璃（Glassmorphism）控制台**，可实时调节引力、流体粘度、霓虹辉光等参数。

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 产物输出到 dist/，可直接部署为静态站点
```

> 需要支持 WebGPU 的浏览器（Chrome / Edge 113+、Safari 26+、Firefox 141+ Windows）。不支持时自动回退到 WebGL2 后端，并默认降到 262K 粒子。
> 麦克风需要 HTTPS 或 `localhost` 环境。

## 功能

| 模块 | 说明 |
| --- | --- |
| 百万粒子 | 默认 1,048,576 个粒子，位置 / 速度 / 目标形状全部驻留在 GPU storage buffer，每帧一次 compute dispatch，CPU 不参与逐粒子计算。面板可切 262K / 524K / 1M / 2M，URL `?n=` 可指定 16K–4M 任意数量。 |
| 流体动力学 | 解析旋度噪声（curl noise）流场，两层八度、天然无散度，粒子像被液体裹挟一样旋转、卷曲。 |
| 低音炸裂 | 分析 20–140 Hz 能量，基于能量通量做节拍检测；每个节拍给粒子一个径向冲击 + 切向湍流，同时辉光闪烁。 |
| 重组 / 变形 | 弹簧把粒子拉回旋转中的目标形状：球体、圆环、三旋臂星系、DNA 双螺旋、空心立方、混沌云。开启“重低音自动变形”后，每累计 8 次重拍就炸开并重组为下一个形态。 |
| 音频源 | 麦克风（关闭回声消除 / 降噪 / 自动增益，保留原始低频）、本地音频文件（按钮选择或直接拖入页面）、内置合成节拍（底鼓 + 锯齿贝斯 + 踩镲，零素材即可体验）。 |
| 后期 | 流光拖尾（AfterImage）→ 霓虹辉光（Bloom，强度随低音实时调制）→ 暗角，ACES 色调映射。 |
| 控制台 | 毛玻璃面板 + 实时频谱 + BASS/MID/HIGH 电平 + 节拍指示灯；参数自动保存到 localStorage；双击滑块恢复默认；移动端变为底部抽屉。 |

### 可调参数

- **引力 Gravity**：朝中心（或鼠标引力井）的吸引力，负值为斥力。
- **流体粘度 Viscosity**：粒子速度向局部流场速度靠拢的速率。越高越“稠”，粒子越被流体带着走，惯性越小。
- **湍流强度 Turbulence**：流场速度幅度，低音 / 中频会进一步放大。
- **重组力 Cohesion**：拉回目标形状的弹簧刚度。调到 0 粒子就只在流场里漂流。
- **炸裂力度 Blast**：低音节拍的径向冲击强度。
- **低音阈值 Bass Gate**：当前低音能量需超过近期均值多少倍才算节拍。环境嘈杂时调高。
- **霓虹辉光 / 辉光半径 / 流光拖尾 / 粒子亮度 / 粒子尺寸**：视觉参数。
- **配色**：Cyber、Toxic、Inferno、Vapor、Ice。

```
src/audio.js        Web Audio 引擎：频段能量、节拍检测、内置合成节拍
src/ui.js           毛玻璃控制台：滑块、配色、形态、粒子数量、频谱绘制

```

### 每帧物理（`particles.js › computeUpdate`）

1. **流场**：`v_flow = curl(ψ(p·scale, t)) · turbulence · (1 + 1.8·bass + 0.6·mid)`
2. **粘度**：`v = mix(v, v_flow, viscosity·dt)`
3. **引力**：沿 `normalize(attractor − p)` 加速，近距离软化，避免奇点抖动
4. **重组**：`v += (R_tilt · R_spin · target · (1 + 0.35·bass) − p) · cohesion`
5. **炸裂**：`v += normalize(p + jitter) · kick · blast · rand`，并附带流场方向的扰动
6. **阻尼 + 限速 + 软边界**，然后 `p += v·dt`

所有力都乘以 `dt`（以 60 fps 为 1），高刷新率屏幕上手感保持一致。

## 实现备注

- 在 TSL 的 `If / ElseIf` 分支之前，共享的随机数要先 `.toVar()`。否则 TSL 只会在第一个用到它们的分支里生成求值代码，其他分支会读到未赋值的变量。
- 粒子颜色在材质中由速度实时计算：静止时是主色到强调色的垂直渐变，越快越“烫”，最终趋向白色。亮度按 `sqrt(1M / 粒子数)` 归一化，换档时整体曝光保持接近。
- 麦克风输入只接 analyser，不接扬声器，避免啸叫。
